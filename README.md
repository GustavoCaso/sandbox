# Sandbox

This is my personal sandbox repository where I publish my little experiments and learning projects across different programming languages and technologies.

## What's Inside

This repository contains various experiments and implementations in:

- **Go** 
- **Rust**
- **Bash**

Each directory contains independent projects that demonstrate specific concepts, implement Unix utilities from scratch, or explore language features.

## Purpose

This is a learning and experimentation space. The code here is exploratory and educational rather than production-ready. You'll find:

- Implementations of common tools (JSON parser, word count, hexdump)
- Network programming examples (servers, clients, socket programming)
- Language-specific features and patterns
- Solutions to programming exercises and challenges

Feel free to explore and use anything you find useful!
